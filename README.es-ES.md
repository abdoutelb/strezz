

Este proyecto se utiliza para realizar pruebas de estrés en sitios web basadas en [locust](https://locust.io/)

Principalmente genera un archivo de Python necesario para que locaust ejecute la prueba de estrés.

- Edita el archivo `.env` con tu URL de prueba. (ej:url=https://google.com/)

Usando docker compose
- `docker-compose up`
 
- accede a `localhost:4000`

Para ejecutar todas las pruebas, ejecuta `jest` desde la CLI
